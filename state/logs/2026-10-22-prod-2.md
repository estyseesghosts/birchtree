- Item 9: terminal `Quarantined` rows do NOT block later sequences
  (blocking on them wedges the host until prune — no operator-resend
  path exists). Documented in code + pinned by test.
- Item 11: RFC 9421 via the doc branch ("explicitly still open"),
  not shipped: no live 4.7 peer exists here to meet the exit criterion,
  and advertising/verifying half a protocol risks interop breakage.
  Legacy RSA + unsigned-refusal pinned by tests.
- Item 8: prune is delete-only; `select_quarantine_victims` /
  `export_quarantine_archive` / `QuarantineRetention` removed (doc's
  "drop the unused export helper"); age-based bound only.
- Item 6: `Stream` refuses with a clear terminal non-persist outcome
  (no proxy path exists in the job context; DTO shapes untouched per
  out-of-scope).
