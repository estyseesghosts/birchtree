# Client API

> Target: Mastodon **4.7.3** (`8ff11c2b`, API v7). Companion to `docs/endpoint-manifest.md` (route inventory) and `docs/compatibility-profile.md` (deviation register). Every route below is implemented and contract-tested unless listed as an honest `404` in §3. Base URL: `https://<domain>`. All `/api/*` responses carry `Vary: Authorization`. REST errors are `{"error":"..."}` except `/oauth/token` and `/oauth/revoke` (Doorkeeper `{"error","error_description"}`). IDs are decimal strings, ordered numerically. Version string: `4.7.3 (compatible; birchtree 0.1.0)`.

## 1. How to connect

**Register an app:** `POST /api/v1/apps` (no auth; `scopes` defaults to `read`; unknown scope → 422; success 200 returns `client_id` + `client_secret` shown once). `GET /api/v1/apps/verify_credentials` (app token) returns the same shape without the secret.

**Authorize (browser, PKCE S256 only):** `GET /oauth/authorize?client_id=&redirect_uri=&response_type=code&scope=&state=&code_challenge=&code_challenge_method=S256` — exact `redirect_uri` match; `scope` must be a subset of app scopes. `GET` renders login or consent page. `POST /oauth/authorize` is form-only (JSON → 415): login (`username` + `password` + TOTP/WebAuthn code when enrolled) sets `birchtree_session` + `birchtree_csrf` cookies (24h) and re-renders consent; consent (`decision=authorize|deny`) redirects `302 <redirect_uri>?code=<one-time-10-min-code>` or `?error=access_denied`.

**Token:** `POST /oauth/token` — `grant_type=authorization_code` (PKCE verifier checked, redirect exact, code one-time) → user token; `grant_type=client_credentials` (confidential apps only, scope ⊆ app scopes) → app-only token; anything else → `400 unsupported_grant_type`. Success: `{access_token, token_type: Bearer, scope, created_at}` — no `expires_in`, no `refresh_token` (non-expiring until revoked/suspended/disabled). OIDC: `GET|POST /oauth/userinfo` (scope `profile`) → `{sub, preferred_username, profile, picture}`.

**Scopes** (any-of, broad OR granular): `profile`, `read`, `read:accounts|blocks|bookmarks|collections|favourites|filters|follows|lists|mutes|notifications|search|statuses`, `write`, `write:accounts|blocks|bookmarks|collections|conversations|favourites|filters|follows|lists|media|mutes|notifications|reports|statuses`, `follow`, `push`, `admin:read|write` + per-resource `admin:read|write:{accounts,reports,domain_allows,domain_blocks,ip_blocks,email_domain_blocks,canonical_email_blocks}`. `read:collections` is a birchtree superset.

**Which credential:** user token (`Authorization: Bearer`) for everything except registration and a few public reads; app-only token only for `POST /api/v1/accounts` + `GET /api/v1/apps/verify_credentials` (on a user route → 422); no token for public reads (`/api/v1/instance`, `/api/v2/instance`, instance sub-resources, public profiles, public/tag timelines, custom emojis, trends, `/system/*` bytes, streaming health) — present-but-invalid still 401s; session + CSRF cookies only for `/api/web/*`; admin routes need user token + staff role checked **before** scope (no role → 403 even with the right scope).

**Revocation:** `POST /oauth/revoke` — always `200 {}` for well-formed requests (empty/unknown included); wrong-client token → 403. Revocation closes the token's streaming connections. Suspension/disablement/deletion also kill tokens permanently; re-enable never restores them.

## 2. Endpoint groups

**Instance and discovery:** `GET /api/v1/instance`, `GET /api/v2/instance` (usage only `{users:{active_month}}`, `translation.enabled:false`, `api_versions:{mastodon:11}`), `GET /api/v1/instance/peers` (+ `peers/search`, `rules`, `domain_blocks`, `activity`, `languages` 68-entry catalog, `translation_languages {}`, `terms_of_service` + `/:date`, `privacy_policy`, `extended_description` — file-backed; unconfigured → honest 404), WebFinger `/.well-known/webfinger`, NodeInfo `/.well-known/nodeinfo` + `/nodeinfo/2.0`, `GET /health` / `/ready` / `/metrics`.

**Accounts, credentials, relationships:** multi-fetch `GET /api/v1/accounts?id[]=` (≤40), `POST /api/v1/accounts` registration, `lookup`, `search`, `verify_credentials`, `update_credentials` (display name, note, locked/bot/discoverable/indexable/hide_collections, fields, `source[privacy,sensitive,language,quote_policy,chosen_languages[],display_media,expand_spoilers,autoplay_gifs]`, `attribution_domains[]`, avatar/header multipart), `GET/PATCH /api/v1/profile` + `DELETE avatar/header`, `:id`, `:id/statuses`, followers/following/endorsements, `relationships`, follow/unfollow/remove/block/unblock/mute/unmute/note/pin/endorse (+un-), `follow_requests` + authorize/reject, `domain_blocks` + `POST preview`, `familiar_followers`, blocks/mutes/favourites/bookmarks, `featured_tags`, `followed_tags`, tags `:id` + follow/unfollow/feature/unfeature, `identity_proofs` (always `[]`), `invite/:code`, email confirmations/check/reset, password edit/set.

**Statuses, interactions, quotes, polls:** multi-fetch `GET /api/v1/statuses?id[]=` (≤20), `POST`, `GET/PUT/PATCH/DELETE :id` (delete returns source mode), `source`, `context` (authenticated remote-thread reads may emit `Mastodon-Async-Refresh`), `history`, `interaction_policy` (PUT/PATCH), favourite/unfavourite, bookmark/unbookmark, reblog/unreblog (direct forbidden: `422 Visibility must be public, unlisted or private`), pin/unpin (limit 5), `favourited_by`/`reblogged_by`, `quotes` + `quotes/:qid/revoke`, conversation mute/unmute, polls `GET :id` + `POST :id/votes` (empty choices → no-op; `choices[]=abc` → 422).

**Timelines:** `home` (user token; 1000 most-recent follows; app-only → 422), `public` (`local/remote/only_media`, feed gates), `tag/:tag` (`local/remote/only_media/any/all/none`, 4-tag cap each, no reblog wrappers), `list/:id` (`replies_policy`, 404 when foreign), `link?url=`. Common: limit default 20 / max 40 (0/non-numeric → empty page, no `Link`); exclusive numeric cursors (non-numeric → 400); `Link: next=max_id, prev=min_id` on non-empty pages only (query echoed minus cursors); anon public/tag `max-age=15, public...`; any authed + home/list `private, no-store`. No `206` regeneration (served complete).

**Media:** `POST /api/v1/media` (sync 200) / `POST /api/v2/media` (202 when delayed), `GET/PUT/PATCH/DELETE /api/v1/media/:id` (206 while pending/processing, 422 when failed, 404 when foreign/missing; only owner's unattached rows), `/system/media_attachments/files/*path` (200/206/416/404, re-sniffed type, `max-age=86400`), `/system/custom_emojis/images/*path`. Transcode: GIF→WebM/VP9 `video`, video→WebM/VP9+Opus, stills→WebP, never `gifv`; single `max_file_size` (default 16 MB) for all types.

**Notifications v1+v2+policy:** v1 index (`limit` 20/40, `types[]`/`exclude_types[]`, `account_id`, `include_filtered`, `supported_types[]`; suspended/gone excluded; `group_key = ungrouped-<id>`), `:id`, `clear`, `unread_count`, `:id/dismiss`, `requests` + `merged` + `:id` + accept/dismiss (+bulk), `policy` GET/PUT; v2 index grouped by `<type>-<anchor>` over newest 2000 rows + `clear` + `unread_count` + `policy` + `:group_key/dismiss` + `:group_key/accounts`.

**Lists, filters, scheduled, markers, preferences, collections:** lists CRUD + `:id/accounts` (GET/POST/DELETE); filters v1 (single-keyword synthesis) + v2 (keywords/statuses sub-resources); scheduled index/show/update/destroy (5-min floor, 300 total / 25 per UTC day caps); markers `GET ?timeline[]=` + `POST` (lock_version → 409); `GET /api/v1/preferences`; collections CRUD + `:id/items` (GET/POST/DELETE) + `revoke` + `in_collections` + `accounts/:id/collections|lists` + minimal `v1_alpha/collections`.

**Search:** `GET /api/v2/search?q=&type=&limit=&offset=&resolve=&account_id=&following=` — accounts/hashtags always DB path; statuses switch by deploy-time `--search-mode=embedded|database|off` (default embedded; restart to change); `resolve=true` without auth → 401; `collections` always `[]`. No `GET /api/v1/search` (removed upstream in 3.0).

**Conversations, suggestions, directory, announcements, trends, annual reports, reports:** conversations list/delete/read/unread (id = thread-root status); suggestions v1 (+DELETE) / v2 (honest local ranking; `Deprecation` on v1); `directory`; announcements list/dismiss/reactions + admin authoring (manual publish/unpublish, no schedule job); trends (`/trends` alias + `tags|links|statuses`, approved-only, `?locale=` inert on tags/links); annual reports index/show/state/generate(202)/read (`:id` = year); `POST /api/v1/reports`.

**Tags, featured tags, custom emoji:** tags `:id` (id = name) + follow/unfollow/feature/unfeature; `followed_tags`; `featured_tags` CRUD + `accounts/:id/featured_tags`; `GET /api/v1/custom_emojis` (picker-visible only).

**Push:** `POST/GET/PUT/PATCH/DELETE /api/v1/push/subscription` (scope `push`, token-bound; RFC 8291 `aes128gcm` + draft-04 `aesgcm` legacy; keyless legacy tickle only; VAPID `exp` 24h).

**Streaming (SSE + WS):** `GET /api/v1/streaming?access_token=&stream=user`, `GET /api/v1/streaming/:channel`, `GET /api/v1/streaming/*any` (SSE unless WS upgrade; WS upgrade path-agnostic), `GET /api/v1/streaming/health`. Wrong host → 301 (when `--streaming-url` set); bare path → 400. Auth: Bearer → query → `Sec-WebSocket-Protocol`; every stream needs a user token; `user:notification` needs `read|read:notifications`, others `read|read:statuses`; list needs ownership. Streams: `user`, `user:notification`, `public(+/local|remote|media)`, `hashtag(+/local)`, `direct`, `list` (+ `only_media`); WS adds `public:media`, `public:local:media`, `public:remote:media`, `hashtag:local`, `user:notification`. Events: `update`/`status.update`, `delete`, `notification`, `notifications_merged "1"`, `conversation` (on `direct` only), `announcement*` (on `user` only); no replay. Bounds (birchtree-only): 512 total → 503; 16/token → 429; 16 subs/WS → 429 frame; 256 frames / 1 MiB queued → close; 30s stall → close; event-queue 4096 overflow → close all.

**`/api/web/*` + bundle:** session + double-submit CSRF only (no bearer): `PUT/PATCH /api/web/settings`, `GET /api/web/embeds/:id` (remote fetch for signed-in sessions), `POST/PUT/PATCH/DELETE /api/web/push_subscriptions/:id` (destroy token-exempt; numeric-id extension needs CSRF when a session acts). `GET /app`, `GET /app/*path` serves the keystodon bundle or `404 Not Found` text until `web_client_dir` is configured.

## 3. Coverage: implemented vs honest 404

~268 method+path rows `implemented` against `config/routes/api.rb` at `8ff11c2b`. Absent answers 404 — never fabricated data.

Out-of-profile (intentional): `POST :id/translate` (no provider); `GET /api/v1/search` (removed in 3.0); `GET /oembed` + `/api/v1/oembed`; `v1_alpha` except minimal `GET collections`; `POST :id/email_subscriptions` (no pinned shape); `DELETE /api/v2/suggestions` (no such upstream route — correctly absent); `GET /api/v1/donation_campaigns` (route exists, always 404, never 204); `GET /api/v1/instance/terms_of_service/:date` (always 404); conditional 404s (peers/activity when gated off, domain_blocks while hidden, terms/privacy when unconfigured).

Two known route-shape bugs (fix first): `GET /api/v1/instance/peers/search` should be `GET /api/v1/peers/search` (`api.rb:159-161`); `POST /api/v1/domain_blocks/preview` should be `GET /api/v1/domain_blocks/preview` (`api.rb:163-165`). Undocumented supersets (register): `GET /api/v1/collections` index + `GET items` (no upstream counterpart); `PATCH` aliases on collections. One missing in-profile row: `GET /api/v1/featured_tags/suggestions` (masto-fe hashtag picker calls it).

## 4. DTO notes

**Status:** scalars + viewer flags + `content`/`text` modes + reblog/account/media/mentions/tags/emojis/collections/quote/`card`/`poll`/`quote_approval`. Gaps: `card` always null; `tagged_collections` always `[]`; `visibility`/`sensitive` unmasked (`limited→private`, `sensitized?` OR missing); `quote_approval.manual` always `[]`; `tags[].id` = name.
**Account:** `acct`, profile, media URLs, counts, moved, fields, tri-state discoverable/hide_collections. Gaps: emojis always `[]`; roles `[]`/absent (real roles only in credential); `feature_approval` hardcoded; `silenced/memorial/email_subscriptions/invalid_handle` never emitted.
**CredentialAccount:** adds `source{privacy,sensitive,language,note,fields,follow_requests_count,hide_collections,discoverable,indexable,attribution_domains,quote_policy}` + `role{id:0|1|2,...}`. Gaps: no `state` object; no `source.spoiler_field`; `collection_limit: 0`.
**Relationship:** all 15 keys exact. **Notification:** `{id,type,created_at,group_key,account,status}` (extra keys live in callers). **Poll:** hidden-totals nulling, author-as-voter, `own_votes` null-vs-`[]`, `emojis:[]`. **MediaAttachment:** `url/preview_url` null-unless-Ready; `remote_url/preview_remote_url` always null; `meta` null when no dims. **Instance v1/v2:** zero-count contact stub, `rules:[]` (real rows on `/rules`), `languages:["en"]` (real catalog on `/languages`), v2 `usage{users:{active_month}}`, simplified thumbnail/icon, `translation.enabled:false`, `min_age:null`, `api_versions:{mastodon:11}`. **Filter v1/v2:** v2 exact; v1 `status_ids[]` superset. **List:** exact. **ScheduledStatus:** `quoted_status_id` stringified, policy default `nobody`. **Conversation:** `{id,unread,accounts,last_status}`; id = thread-root status (D43).

## 5. Parsing, pagination, errors, rate limits, idempotency

Form-or-JSON everywhere except `POST /oauth/authorize` (form-only → 415 JSON). Flattening is Rails-like (nested → `a[b]`, arrays → repeated `a[]`, indexed objects → `a[N][field]`, numbers/bools → text, null absent). Multipart capped spool; `key` + `key[]` arrays; `has` distinguishes present-empty vs absent (`languages[]` absent-keeps, present-empty-clears — JSON `[]` reads as absent). Nested `poll[]`, `fields_attributes[]`, `keywords_attributes[]`, `source[]`, `account_ids[]`, `status_ids[]`, `id[]`, `types[]`, `any/all/none[]`, `timeline[]` all parsed. Pagination: limit default 20 / max 40 (domain blocks 100/200, trends offset/limit 10); exclusive numeric cursors (non-numeric → 400); `Link next=max_id/prev=min_id` on non-empty pages only (query echoed minus cursors). Errors: `400` cursor/param/malformed-JSON, `401` token, `403` scope/role/pending, `404` record vs `Not Found` sub-routes, `409` marker conflict, `413` over-cap, `415` wrong body, `422` validation, `429 + Retry-After + X-RateLimit-*`; `202` delayed (v2 media, annual generate); `206` unready (media show, ranged bytes); never `204`. Rate limits: general 1500/5min + per-route sensitive budgets (login 10, token 30, registration 10/30min, password/reset 5–10/30min + per-address 3, app-create 30/30min); trusted-proxy-aware IP identity. `Idempotency-Key` on `POST /api/v1/statuses` (1h per-account replay); other writes idempotent by unique rows.

## 6. Where we differ, and what masto-fe breaks

Media (WebM/VP9+WebP, never `gifv`, EXIF kept, single size cap); caps (home 1000, exclusive lists, no `206`, tag excludes reblogs, read-time ancestors, search default-on); privacy-stricter (blocked/muted 404, bookmark denied, private trends hidden, permanent token kill); wire (JSON bodies, `Link` echo, `Vary`, `private,no-store`, malformed-JSON 400-vs-404, streaming bounds/301, `direct` conversation-only, `public:remote` carries remotes); extensions (`read:collections`, `chosen_languages`, `home_mention_policy`, follow `languages[]`, v1 `status_ids[]`, numeric-id web destroy, collections superset).

masto-fe breaks: blank `/app` until bundle installed; hashtag-suggestion picker + email subscribe 404; peer-search pinned path 404; translate/donate/oembed/v1-search/`v1_alpha` gated; GIFs as plain WebM video (needs WebM/VP9+WebP); search Collections always `[]` (default-on differs); push needs VAPID; surges get 429/503 + reconnect; privacy-stricter shows less; remote previews null, account emoji local-only, resolve/embeds need auth; year-in-review async, announcements manual, metrics refused-with-reason, IP/email enforcement partial, MFA no REST enrollment, admin API+CLI only. Parity suite, live interop, contract freeze, keystodon smoke, and Phase-8 perf have never run — expect papercuts.
